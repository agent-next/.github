# Agent Next

**Building an agentic world.**

We believe the next era of work will be carried out by agents: systems that pursue goals over long horizons, coordinate with one another, and produce results that can be checked.

We build agent-native systems designed for large-scale autonomous work in the cloud. People set direction, oversee execution, and provide feedback; agents carry out the work.

## Research

- **Agent infrastructure.** Models, runtimes, and coordination that let large agent teams operate reliably.
- **Verification.** Methods for checking agent work and establishing the limits of its reliability.
- **Learning from experience.** How agents can learn from outcomes, feedback, and failures.
- **Agents for science and beyond.** Autonomous agents applied to discovery and other real-world work.
